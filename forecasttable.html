Suggestion Rules

Rule 1 - Pcpn Type
IF Ltg contains M or H
THEN suggest ... TRW
Rate L or L-M: suggest RW TRW (>=5C) or SW TRW (<5C)
Rate M, M-H or H: suggest R TRW (>=5C) or S TRW (<5C)
Rule 2 - Fire Danger Trend
IF Low RH <= 30 AND Pcpn nil/trace (<=30% covg) → UP
IF Pcpn >= 50% covg AND measurable (>=0.5mm) → DN
Rule 3 - Low RH
Pcpn >= 70% rate H → suggest 55%
Pcpn >= 60% rate M+ → suggest 40%
Rule 4 - Pcpn Covg
If Pcpn Type set and Covg empty → suggest >10L
Always shown. No entry = red warning. Differs = amber. Matches = green.
Rule 5 - Lightning from TRW
IF Pcpn Type Final contains TRW
THEN suggest Ltg = M/I
Ltg starts M or H → amber caution
Ltg starts L or empty → red warning
Rule 6 - TRW Must Be Paired
TRW cannot stand alone in Pcpn Type Final.
Must be paired with R, RW, S, or SW
e.g. RW TRW or R TRW
Standalone TRW → red warning

Caution Flags

Significant Change
Max Temp: >= 5C diff vs GOA or OBS → tooltip warning
Other numeric: >= 10 diff → tooltip warning
Zone Adjacency Caution
Max Temp differs from adjacent zone by >= 10C
Low RH differs from adjacent zone by >= 20%
→ shown as inline label + tooltip on Final cell
